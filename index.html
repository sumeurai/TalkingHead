1 · API & avatar

Developer console · used with secretKey

Developer console · do not commit

POST /v1/access/auth → data.accessToken

Required for /audio-to-face/dt · from Studio or GET /v1/avatars/models/{modelId}. Poll that GET to download files[] onto your server.

Clone voice for TTS · POST /v1/tts with voiceId

Directory you host after downloading GET /v1/avatars/models/{modelId} → files[]. All files must share the same directory (AvatarJS loads {modelUrl}{name}; keep original name). Same-origin relative path works too, e.g. ./my-model/. Do not paste API downloadLink or files[].url (24h temp). This is createAvatar({ modelUrl }).

After you download files[], put them on your server (same folder, original names), then paste that directory URL above. Selecting files here does not load the avatar.
